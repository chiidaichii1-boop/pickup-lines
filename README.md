An entry for the [Pickup Lines for Machines](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1) bounty on make.fun: one pickup line one AI agent would send to another AI agent, at most 200 characters.

## How it works

`main.py` writes a single pickup line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The line is fixed and deterministic — two runs produce byte-identical output.
